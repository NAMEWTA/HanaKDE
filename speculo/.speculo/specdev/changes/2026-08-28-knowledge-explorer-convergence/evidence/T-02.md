## 1. 实现摘要

Knowledge 生产页面不再挂载平行的 Knowledge Explorer/Editor，而是直接组合已有 `DeskSection`、`DeskTree`、`PreviewPanel` 与 `WorkspaceFileChangeBridge`。因此目录加载、标签页、Markdown/代码编辑、保存、Watch、冲突处理和文件预览与聊天工作台共用同一套组件、store 和 actions。

文件复制、剪切与粘贴补入 DeskTree 的右键菜单和键盘路径，复制由 mount-aware file service 统一处理并生成无冲突目标名；顶部工具栏继续只保留新建、打开、导入等全局命令。旧 `RECOVERY_REQUIRED` 删除日志在原文件与回收载荷均已不存在时可安全终结，不再永久锁住当前工作区。

插件页不再以超时伪装 ready；iframe 只在签名 URL 可用后挂载，并以真实 load/handshake 决定状态。针对 `file://` 顶层拒收 `SameSite=Strict` asset cookie 的 Electron 行为，插件 HTML 将资源地址改写为短时签名 session 路径，同时保留 cookie 兼容路径。
