## 6. 残余风险与后续

- `macOS x64` runtime and cross-arch DMG remain unverified on this arm64 host. The standalone native helper cross-compile now passes, but `arch -x86_64` execution is unavailable; T-23 is not a universal macOS platform sign-off until the runtime/package matrix runs.
- Hardware sleep/wake and actual event loss/reconcile require a sleep-capable platform runner; SIGSTOP/SIGCONT is only the deterministic process-lifecycle probe.
- Current dev Electron and Web Open Office flows pass at `2421bfed`; the earlier desktop window/dialog failure was removed by T-15 strip-only loading and the T-20 readiness/store corrections. This does not prove a production `.app` rebuilt from `2421bfed`: the retained arm64 package/DMG and todo launch predate the final T-20/T-16 product commits, so packaged Office/History direct flow remains unresolved.
- The harness still does not prove descriptor counts, physical hardware sleep/wake with actual event loss, or product-level gap/reconcile after wake. SIGSTOP/SIGCONT and raw `fs.watch` observations are deterministic fixture coverage, not substitutes for those rows.
- The pre-adapter launch probe emitted renderer-side `event-bus` subscriber errors because the external todo plugin used the declared type-first `bus.subscribe(eventType, handler)` overload while `<Path>core/plugin-context.ts</Path>` forwarded only callback-first arguments to `<Path>hub/event-bus.ts</Path>`. Approved deviation D-T23-02 adds the bounded plugin-boundary adapter in `<Path>core/plugin-context.ts</Path>` with regression coverage in `<Path>tests/plugin-context.test.ts</Path>`; the 140-test suite and targeted typecheck pass. A current packaged relaunch copied that exact todo `0.0.5` plugin into an isolated temporary `HANA_HOME`: the plugin loaded and activated on startup, registered its route/tools, emitted no event-bus subscriber errors, and unloaded cleanly. Its optional task-handler requests reported the documented unavailable-capability warnings and degraded safely; they are unrelated to the repaired bus overload.
