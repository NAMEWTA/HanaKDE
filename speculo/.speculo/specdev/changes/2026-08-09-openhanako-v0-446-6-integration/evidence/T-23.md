## 6. 残余风险与后续

- `macOS x64` compile/runtime and cross-arch DMG remain unverified on this arm64 host; T-23 is not a universal macOS platform sign-off until that matrix runs.
- Hardware sleep/wake and actual event loss/reconcile require a sleep-capable platform runner; SIGSTOP/SIGCONT is only the deterministic process-lifecycle probe.
- Interactive Electron Knowledge/Office direct-flow E2E was not run in this headless command session; existing T-20/T-21 focused suites and package inventory remain the available evidence.
- The app emitted repeated renderer-side `event-bus` subscriber errors during the short launch probe; no startup failure marker appeared, but this should be investigated before final umbrella acceptance.
