## 1. 实现摘要

Knowledge 主来源现在只消费 ResourceEventBus 和共享 baseline difference；它不再为 `main` 保留私有 watcher 或完整 root walk。source coverage 使用原子 generation rebuild，resource coverage 只重新读取列出的资源；Search、IR、Registry 和 Knowledge DB 仍独立于 History。

本轮审查修正了三个可能造成静默分叉的时序：正在读取的增量 hint 在较低 cursor baseline 到达时会重放；baseline 构建期间出现的新 gap/directory repair 会在旧 baseline 后请求新的 scoped repair；低于 active repair cursor 的 baseline 会 fail closed，即使已有更高的 accepted cursor。最终回归通过公共 Search 查询确认索引正文为 `event-version`，而不是中间 `baseline-version`。
