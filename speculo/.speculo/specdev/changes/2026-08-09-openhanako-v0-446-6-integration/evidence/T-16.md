## 1. Delivered behavior

The renderer exposes one main-only History flow from the Workbench workspace
header and from strictly correlated Agent projections. The shared application
store owns only modal intent and scope generation; one global modal host owns
the files/deleted/timeline/diff/restore/health UI. No second file cache or raw
filesystem path was introduced.

The modal reconstructs bounded snapshots from the existing History diff route,
re-reads the current ResourceIO version immediately before restore, and writes
through `write-expected-version`. Independent abort/active guards prevent stale
file, version, snapshot, or refresh responses from crossing modal generations.

  until the existing slice and modal were mounted in the global renderer host.
- **D-T16-02:** approved and closed. Agent correlation cannot substitute for a

  existing workspace header as a fixed 28px icon control with tooltip/ARIA.

  diagnostic run showed the fixture intentionally persisted the Knowledge tab;
  the final flow now performs the real visible tab transition before opening
  History. No production bypass or private History database mutation remains.
