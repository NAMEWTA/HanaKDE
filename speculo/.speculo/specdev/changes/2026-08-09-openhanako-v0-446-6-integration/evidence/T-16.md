## 1. 实现摘要

The renderer now has a main-only History entry and modal state with active and
deleted files, version timeline, line diff reconstruction, current-resource
preflight, expected-version restore, conflict/error/health states, retry, and
keyboard/ARIA/narrow-layout styling. The UI keeps only modal intent in the
store; file bodies and versions remain request-scoped and are invalidated by
abort controllers plus a monotonic modal scope generation.

Restore uses ResourceIO's main-scoped `write-expected-version` request and never
omits the current expected version. Successful restore refreshes the file list;
conflicts remain visible and do not claim success. The renderer API rejects
unsafe relative paths and validates all response DTOs before presentation.
