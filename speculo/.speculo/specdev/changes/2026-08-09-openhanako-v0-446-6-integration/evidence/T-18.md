## 1. 实现摘要

The file mention search owns one cancelable identity at a time. A new query, scope change, tab change, menu close, or unmount retires the prior identity; only the current identity may update results or loading. The existing desk search adapter remains unchanged, so cancellation prevents stale UI writes even though the adapter does not yet accept an `AbortSignal`.
