## 1. 实现摘要

The file mention search owns one cancelable identity at a time. A new query, scope change, tab change, menu close, or unmount retires the prior identity; only the current identity may update results or loading. Correction D-T18-03 passes that identity's `AbortSignal` through `searchDeskFiles` to `hanaFetch`, so clear/unmount physically abort the transport in addition to preventing stale UI writes. Expected aborts return the stable empty result without a false provider-error log.
