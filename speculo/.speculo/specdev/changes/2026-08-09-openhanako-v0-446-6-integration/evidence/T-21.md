## 1. 实现摘要

Production server packaging now uses Vite SSR with `ssr.noExternal=true`, preserving
the existing explicit `rollupOptions.external` install contract while retaining
`anydoc-child.cjs` and bundled `html-child.ts` beside `bundle/index.js`. The build
fails closed if a child runtime is inlined as a data URL or its staged file is absent.

The secure filesystem helper is built for the requested macOS architecture with
`-arch` and `lipo` verification, copied into `dist-server/<os>-<arch>/dist-secure-fs`
before seed signing, and located at runtime from the trusted absolute `HANA_ROOT`.
Linux remains an explicit skip; Windows uses the existing target MSVC architecture
selection and is CI/platform-gate owned.

Open export closure now includes the extraction and Workspace runtime sources,
removes one stale manifest path, registers dynamic process boundaries, and has a
deterministic regenerated closure receipt. CI invokes the helper build before direct
server builds; package `build:server` invokes it before the full server builder.

## 5. 双轴审查

### Standards axis

- All ordinary implementation changes stay within T-21 writable paths.
- The six deviations are narrow, recorded before their read-only path edits, and
  do not add a product API, alternate write path, compatibility fallback, or release action.
- Helper output is target-arch checked and copied before signing; missing supported
  platform input fails early instead of shipping a host binary.

### Specification axis

- Explicit external dependency truth remains rooted in `package.json`/lockfile;
  SSR noExternal prevents accidental untracked production dependencies.
- Full and open server bundles share the same extraction child runtime contract;
  open export materializes every source needed by the open graph.
- ResourceIO helper lookup uses only trusted absolute `HANA_ROOT` or the existing
  source fallback; Linux/open unsupported cases remain fail-closed.
- Native Windows execution and final cross-platform gates are not inferred from
  macOS static source checks.
