## 1. Implementation Summary

The upstream root-hash, private watcher, and private baseline walk were replaced with a main-bound logical History consumer. `activateMain()` accepts only an authorized `sourceKey: "main"` binding, derives a private SQLite location from an opaque `historyStoreKey`, verifies that location before creating a store, subscribes to shared Workspace observations and projected main resource events, and reads bytes through the injected main-bound seam.

The new `hana.file-history.main.v1` schema rejects incomplete or legacy databases rather than migrating or discovering profiles. It retains bounded text snapshots with content/version dedupe, 60-second merging, rename continuity, move-out tombstones, line diffs, 30-day retention, and a 500 MiB compressed-store quota. The route now addresses only the already-authorized current main service; it rejects raw root, public workspace identity, and agent selectors, exposes timeline/diff only, and deliberately leaves restore to T-15.
