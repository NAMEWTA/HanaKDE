## 1. 实现摘要

Knowledge tree 复用 Desk `getFileIcon`、共享 `ICONS`、file-kind 和既有 open/preview policy，并把右键选择交给 `KnowledgeLayout` 的单一 action adapter。文件/文件夹按能力显示剪切、复制、粘贴、重命名、移入回收站、复制相对路径、复制绝对路径、打开文件夹和默认应用打开。通用 `ContextMenu` 增加可选 icon、menu/menuitem 语义、tooltip 和 ARIA 名称。Native `copyPath` 只在 Main 内写系统剪贴板，Renderer 从不接收绝对路径；Web/remote/no-grant 不显示 native 动作。

## 5. 双轴审查

### Standards axis

通过。审查发现初版语义动作误用了通用 back/file/settings icon，随后在既有 Desk `ICONS` 中补齐 cut/copy/paste/rename/trash，并由 Knowledge 直接复用；没有引入第二套 SVG 文件、file-kind parser 或 previewer。最终测试、typecheck、lint 和 renderer build 在修正后重跑通过。

### Specification axis

通过。复核 source root 时把 native action 条件收紧为“必须是实际资源”，空 relative path 的来源根不获得路径动作；本地已 materialize 的挂载资源仍可使用 grant，Web/remote 通过能力矩阵隐藏。`main` 的可见名称统一为“工作目录”，内部 sourceKey 不改。

## 6. 路径所有权审计

实际修改均在 T-03 expected/writable 范围；`KnowledgeWorkspace.module.css` 与共享 Desk icons 已同步进 Ticket 路径契约。`<Path>desktop/src/react/ui/ContextMenu.tsx</Path>` 由 T-03 独占。`<Path>server/routes/knowledge-workspace.ts</Path>` 与 T-01 在同一实现者下串行分区：T-01 拥有 owner composition，T-03 拥有 native grant action。

## 7. 偏差与决策

- 无公共协议偏差；`copyPath` 是既有 grant action union 的向后兼容扩展，仍由 Main-only credential 和一次性 grant 保护。
- 没有安装新 icon 依赖；仓库已有共享 Desk `ICONS`，按“尽可能复用”扩展该单一集合。
- 一次审查探针曾尝试把所有 mounted source 都视为不可 native，结合现有 materialize 合同后判定该假设错误并移除；最终规则以实际 runtime capability 为准。

## 8. 残余风险与后续

默认应用行为仍依赖宿主 OS 能力，Web/远程按设计隐藏而非模拟。当前 Playwright 覆盖 Web Open 降级；Desktop 的 grant/credential/一次消费由 route 与 service tests 覆盖，未在本 change 中启动真实外部应用以避免测试副作用。
