# 档案管理领域

**档案（Dossier）**：围绕一个实体或项目建立的结构化归集单元，承载该对象的属性、联系人关系和资料关系。
_Avoid_: 文件夹、系统归档状态、Archived Record

**档案类型**：用于区分个人、公司、项目、企业等归集对象类别的模板；系统提供内置模板，用户也可创建自定义类型和 typed fields。
_Avoid_: 用标签临时代替稳定类型

**档案属性**：直接描述档案所代表实体或项目的结构化字段和值。
_Avoid_: 无类型键值字符串、讨论备注

**联系人（Contact）**：拥有独立稳定身份、可被多个档案复用的联系人实体；档案通过带角色的关系关联联系人。
_Avoid_: 档案内联系人副本、把关系角色写进联系人本体

**档案资料**：与档案关联、归入当前工作区档案库受管路径的文档或其他用户资源及其元数据；外部资料加入时先形成工作区内副本。
_Avoid_: 浏览器临时上传、物化绝对路径

**工作区档案库**：当前打开工作区内固定为 `Dossiers/` 的唯一档案库根；承载档案资料受管副本，结构化权威数据是否也在其中仍由当前 change 决定。
_Avoid_: 插件安装目录、HANA_HOME plugin-data、外部绝对路径集合

**智能档案**：同时提供结构化档案管理、元数据检索、Agent 工具、自动摘要和智能关联的首版产品闭环；首版不提供正文全文检索。
_Avoid_: 无来源摘要、不可追溯的自动分类

**单用户档案库**：由本机单个用户使用的工作区档案库，不承诺账号共享、实时协作或并发副本自动合并。
_Avoid_: 多用户协作数据库

**档案字段**：模板内具有稳定 id、type 和 order 的 typed field；首版类型包括文本、长文本、数字、日期、布尔、枚举、URL、邮箱和电话。
_Avoid_: 无类型键值、用展示名称作为字段身份

**资料元数据检索**：仅基于资料标题、分类和标签进行的首版搜索能力，不读取或索引资料正文。
_Avoid_: 全文检索、把摘要当作正文命中

**档案 Agent**：可执行有界档案查询与 CRUD、添加联系人和资料、生成摘要的 Agent 工具集合；批量修改、删除和覆盖文件仍需确认。
_Avoid_: 无审计自主删除、静默接受智能关联

**全局模型访问**：默认允许当前配置模型处理档案资料且不要求逐档案确认的设置；用户可全局关闭，产物必须保留资料来源。
_Avoid_: 正文写入日志、隐藏模型访问状态

**规范化存档**：以档案为边界组织属性、联系人和受管资料的产品目的；首版不表达档案之间的公司、项目、隶属或图谱关系。
_Avoid_: 实体关系管理、知识图谱

**档案回收站**：保存已删除档案及受管资料 30 天的可恢复状态；到期最终清理仍需引用检查和审计。
_Avoid_: 立即物理删除、解除关系即删除联系人

**档案受管副本**：位于目标档案目录内的资料副本；任何目标目录外来源都先复制进入，已在目标目录内的文件才建立相对引用。
_Avoid_: 工作区其他位置原位引用、静默覆盖同名文件

**档案迁移单元**：工作区内完整的 `Dossiers/` 目录，包含所有结构化权威数据和受管资料；插件私有缓存不属于迁移权威。
_Avoid_: 只迁移资料文件、依赖 HANA_HOME 恢复档案结构

**AI 资料入口**：交给 Agent 的工作区相对档案目录或清单文件引用；Agent 使用受控资源工具按任务需要读取必要文件或片段。
_Avoid_: 预先发送完整资料、宿主绝对路径、全量正文上下文

**档案清单**：位于 `Dossiers/` 内、描述档案或联系人的版本化结构化权威文件；根级 SQLite 只是可从清单重建的查询索引。
_Avoid_: SQLite 唯一真相、仅靠目录名推断语义

**内置档案模板**：首版提供的个人、组织、项目三类模板；公司、企业和机构属于组织实例，自定义类型由模板复制演进。
_Avoid_: 为每个组织性质建立系统类型

**显式 AI 任务**：由用户操作或 Agent 当前任务明确触发的资料按需读取；全局模型授权不触发后台自动扫描。
_Avoid_: 导入即自动外发、页面加载即调用模型

**插件盒子**：`plugins/<plugin-id>/` 下自包含 manifest、Page、routes、tools、领域实现、assets 和测试的实现边界，只消费公开 Hana 插件 SDK。
_Avoid_: 修改 core/server/desktop/shared/packages、调用内部 Knowledge Workspace API

**Dossiers 插件**：manifest id 为 `dossiers`、实现根为 `plugins/dossiers/`、用户可见名称为 `Hana Dossiers / 档案` 的内置 full 插件。
_Avoid_: archives 插件、把展示名称作为持久身份

**dossier.json**：每份档案目录内唯一的版本化档案清单权威；联系人和类型使用根级 JSON 清单，`catalog.sqlite` 只保存派生查询投影。
_Avoid_: Markdown 第二权威、SQLite 唯一真相

**档案包**：单份档案导出的自包含 zip，包含档案清单、联系人快照、受管资料和校验清单；不等于完整档案库迁移。
_Avoid_: 未校验 zip、联系人快照覆盖全局联系人

**普通活动**：用于用户查看日常档案变化、默认保留 1 年的事件记录。
_Avoid_: 永久安全审计、当前档案事实

**永久审计**：迁移、删除、恢复和安全相关的最小化审计记录，不包含资料正文、联系人敏感值或完整模型输入。
_Avoid_: 普通 UI 活动、敏感内容日志
